# InAmigos Foundation website

A simple, static website for InAmigos Foundation and its six projects.

## Pages

| File | What it is |
|---|---|
| `index.html` | Home page: about, reach, projects, registrations, team, events, get involved, contact |
| `project-seva.html` | Project Seva: food and clothing |
| `project-bachpanshala.html` | Project Bachpanshala: children's education |
| `project-udaan.html` | Project Udaan: women's empowerment |
| `project-jeev.html` | Project Jeev: animal welfare |
| `project-prakriti.html` | Project Prakriti: environment |
| `project-vikas.html` | Project Vikas: skills and employability |
| `inamigos-site.html` | All pages bundled into one file, for sharing or previewing |
| `logo.png` | InAmigos logo |

## Viewing

Open `index.html` in a browser, or publish with GitHub Pages
(Settings → Pages → Deploy from a branch → `main` / root).

Every page has light and dark themes and works on phones. No build step is needed.
